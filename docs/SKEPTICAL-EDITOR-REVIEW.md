# Repository setup for skeptical-editor review

The installed `read-research-paper` skill contains the portable
skeptical-editor protocol. Its paired `write-research-paper` skill contains the
reusable direction and launcher templates. Their canonical source is recorded
in [`SKILLS.md`](SKILLS.md).

Read the portable protocol completely before supervising a run. Ordinary
review artifacts belong in `.research-scratch/<paper>/skeptical-editor/`.
Preserve a completed report durably only when the owner authorizes that record.
Launch the editor in a fresh context with no inherited conversation or research
state, and withhold `evals/`, drafting history, earlier reviews, vocabulary
reports, and proposed repairs.
