# Live paper workspace

Use this directory only when the owner explicitly authorizes paper writing or
editing. A research result, durable note, canonical checkpoint, or standalone
report does not independently authorize changes here.

Once authorized, follow the exposition standards in
[`../docs/PAPER-WRITING.md`](../docs/PAPER-WRITING.md), and
[`../docs/FIRST-READER-REVIEW.md`](../docs/FIRST-READER-REVIEW.md) when a
manuscript is ready for a forward-blind reading. The mechanical wording check
lives in [`vocab/`](vocab/README.md).

Projects may replace this guide with their preferred source structure and build
instructions.
