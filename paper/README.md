# Live paper workspace

Use this directory only when the owner explicitly authorizes paper writing or
editing. A research result, durable note, canonical checkpoint, or standalone
report does not independently authorize changes here.

Once authorized, write and revise through the `write-research-paper` skill
recorded in [`../docs/SKILLS.md`](../docs/SKILLS.md), following this
repository's conventions in
[`../docs/PAPER-WRITING.md`](../docs/PAPER-WRITING.md). When a manuscript is
ready for independent reading, set the run up as described in
[`../docs/FIRST-READER-REVIEW.md`](../docs/FIRST-READER-REVIEW.md) or
[`../docs/SKEPTICAL-EDITOR-REVIEW.md`](../docs/SKEPTICAL-EDITOR-REVIEW.md). The
mechanical wording check lives in [`vocab/`](vocab/README.md).

Projects may replace this guide with their preferred source structure and build
instructions.
